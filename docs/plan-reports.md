# 計画データの相談事項

道の駅の整備計画データ（`data/plans.json`）を調査していて出た、データの列に書けないものを並べる — メンテナの判断が要る相談事項と、調査でしか気づけず台帳の外を直さないと解決しないこと（`data/cities.json` がまだ実世界に追随していない場合など）。

**調査セッションは末尾に追記するだけ。** 対応と消し込みはメンテナが行う。

書式は 1 駅 1 項目。日付・駅名・都道府県を頭に置き、文単位で完結させる:

- **YYYY-MM-DD 道の駅◯◯（◯◯県）** — 何を判断してほしいか、または何を直してほしいか。[出典](URL)

## 相談事項

- **2026-08-19 道の駅 幌延町（北海道）** — 令和8年6月の町議会で、整備中だった多世代交流施設（道の駅を含む複合施設）の一時凍結が発表された。なお令和5年6月の町議会では町長が「道の駅ではないかもしれない」と述べており、この施設が最終的に「道の駅」として整備されるかは元々不透明だった。[出典](https://www.hokkaido-np.co.jp/article/1325528/)
