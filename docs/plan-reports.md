# 計画データの相談事項

道の駅の整備計画データ（`data/plans.json`）を調査していて出た、データの列に書けない相談事項を並べる。

**調査セッションは末尾に追記するだけ。** 対応と消し込みはメンテナが行う。

書式は 1 駅 1 項目。日付・駅名・都道府県を頭に置き、文単位で完結させる:

- **YYYY-MM-DD 道の駅◯◯（◯◯県）** — 何を判断してほしいか。[出典](URL)

## 相談事項

- **2026-08-12 道の駅 あやせ（神奈川県）** — 2024 年 7 月就任の市長が総合計画の見直しを諮問し、道の駅整備は報道で「棚上げ」と表現されている。2025 年 4 月に総合計画審議会が「道の駅は手段の一つ」とする答申を出したが、市による凍結・中止の宣言は見つからないので `status` は `計画中` のまま。当初の 2027 年度開業目標に市長が「こだわらない」と述べているため `date` も空のままにした。見直し後の総合計画が確定すれば方針が読めるはずなので、次回はそこを手掛かりに調べるとよい。[答申の記事](https://www.kanaloco.jp/news/government/article-1166263.html)
- **2026-08-12 道の駅 横須賀市（神奈川県）** — 市は 2017 年度の調査で「市内には条件を満たす適地はなかった」とし、幹線道路整備の進捗に応じて必要なら再検討する、という立場を市サイトで示していた。凍結・中止の宣言ではないので `status` は `計画中` のまま動かしていないが、実質的に止まっている可能性がある。市の該当ページは現在 404 で、検索エンジンのキャッシュ経由でしか内容を確認できなかった。[404 の URL](https://www.city.yokosuka.kanagawa.jp/voicebank/9052.html)
- **2026-08-12 道の駅 勝浦市（千葉県）** — 唯一の出典だった市の基本計画（案）PDF が 404 になったが、代替が見つからず 0 件ガードで残した。`status` が `計画中` である根拠が現在たどれない。市の公式サイトを `site:` 検索しても道の駅関連ページに当たらず、事業が続いているかも確認できなかった。[404 の URL](https://www.city.katsuura.lg.jp/div/soumu/pdf/public-comment/mitinoeki_kihonkeikakuan.pdf)
