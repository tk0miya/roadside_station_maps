# 計画データの相談事項

道の駅の整備計画データ（`data/plans.json`）を調査していて出た、データの列に書けないものを並べる — メンテナの判断が要る相談事項と、調査でしか気づけず台帳の外を直さないと解決しないこと（`data/cities.json` の古さ）。

**調査セッションは末尾に追記するだけ。** 対応と消し込みはメンテナが行う。

書式は 1 駅 1 項目。日付・駅名・都道府県を頭に置き、文単位で完結させる:

- **YYYY-MM-DD 道の駅◯◯（◯◯県）** — 何を判断してほしいか、または何を直してほしいか。[出典](URL)
